# 韩站扩采与真实选项库交付

## 范围与结果

本轮针对“远远不止这些”的反馈扩采，不以虚构价格补齐页面。

- 完整读取女神门票七个纯韩文 sales_event sitemap，去重发现 **34,901** 条链接。
- 首轮受限扩采抓取 **120** 个活动详情，成功解析 **69** 个活动的 **210** 个选项。
- 首轮其中首尔且命中十项目的 **49** 个活动、**145** 个选项；其他地区或词典外 **20** 个活动。
- 首轮跳过 **51** 页：医院投影冲突 **31**、选项事实冲突 **20**。
- 随后补做四页诊断，及对首轮医院冲突的 **31** 页受限复核；复核解析成功 **26** 页、仍跳过 **5** 页。
- 合并此前样本、按首尔与词典预筛、活动/选项 ID 去重后：**71 个活动、37 家机构、218 个选项**。
- 保守结构化 **124** 条，待复杂抽取 **94** 条。可计算单位价 **28** 条，其余不排名。
- 已覆盖肉毒素、玻尿酸、超声刀、热玛吉、Shurink、丽珠兰、水光、皮秒、Potenza；Inmode 暂无已结构化样本。

“发现链接”“请求页面”“入库选项”“完成结构化”“可计算单价”是不同指标，不相互冒充。
以上不是全站采集，也不是跨平台全量覆盖。

## 修复依据

同页医院完整记录和摘要记录可能共享 ID，摘要 address/addressDetail 为 null。
仅对非空值全部一致的字段做补齐，两个实际地址/名称不一致仍拒绝。增加对应离线回归。

有些选项同 ID 出现不同 price，甚至不同 name，例如复核页 32743 的 option 440609
出现 25,300 与 30,800 两个原价。没有将其误当券价、选最便宜值或用模型猜测，继续跳过。

规则抽取只认明确剂量与品牌，品牌不从可能包含其他商品的活动标题转移到选项。
指定院长、初访等条件不进默认排名；玻尿酸溶解针不归为填充注射。
规则输出更新会失效旧展示投影，不让已拒绝的旧结果继续显示。

## 网站

- `/activities/`：全部已核实原始选项，医院、地址、韩文原名、标价/券价分列、次数、日期、原链接；支持文本搜索。
- 首页增加已入库活动/原始选项/结构化条目计数和选项库入口。
- 项目页增加“信息待确认”分区，缺剂量不混进默认排名；原选项名可查看/搜索。
- 项目没有可排名条目时默认打开实际有内容的分区，不再看似空页。
- API 凭据不进入静态站数据。

## 分析与验收

使用用户指定兼容网关的 Gemini 四代对真实只读视图做有界开发分析，模型响应名
`gemini-4-hydrogen`。只提交 schema 校验草稿，页面价格/机构名称仍按 ID 从库渲染。
不将开发草稿冒充已通过完整自动工具循环、费用控制和生产发布的正式日报。
供应商费率未知，不编造美元成本，不启用自动收费任务。

真实 100 条未标注选项已导出 `tests/golden/unlabeled.jsonl`，不是伪造金标。
缺设计方标注，M2 准确率仍未验收；Babitalk、生产 ARM 运维和公网部署也未完成实机验收。

仍遵守原交接约束：robots 开启、单并发、固定间隔至少五秒、无重试/代理/登录/验证码处理，
不访问禁止 API。不采 Unni；不保存患者评价、昵称、照片或医生个人资料。
HTML 只驻内存，磁盘只持久化允许事实字段。
